**Project Title**

Restaurant Mobile Ordering System

**Objective**

Develop a mobile application that allows customers to order food directly from the restaurant, pay via mobile money, and receive delivery on campus.

**Problem Statement**

The current ordering process relies on phone calls, which causes inefficiencies such as order miscommunication, lack of tracking, and slow service.

**Solution**

A mobile ordering system where users can browse the menu, place orders, and pay digitally.

**Key Stakeholders**
| Stakeholder | Role |
| --- | --- |
| Restaurant owner | Business owner |
| Developers (Darks) | System builder |
| Customers | End users |
| Delivery riders | Logistics(Later) |
